# Source and adaptation

This project adapts the Hashing & Strings topic from **DSA Grand Slam** by GitHub user **hiepnnguyentcu**:

- Repository: https://github.com/hiepnnguyentcu/dsa-grand-slam
- Source commit: `efdf8f18e5917df2db9e51193e2fb7f066c099d8`
- Source topic: https://github.com/hiepnnguyentcu/dsa-grand-slam/tree/efdf8f18e5917df2db9e51193e2fb7f066c099d8/hashing_strings
- Java adaptation prepared for: https://github.com/phuthanh03012003

| Original Python file | Java adaptation |
|---|---|
| `hash_lookup.py` | `hashing_strings/HashLookup.java` |
| `frequency_signatures.py` | `hashing_strings/FrequencySignatures.java` |
| `set_sequences.py` | `hashing_strings/SetSequences.java` |
| `majority_vote.py` | `hashing_strings/MajorityVote.java` |
| `string_building.py` | `hashing_strings/StringBuilding.java` |
| `expand_centre.py` | `hashing_strings/ExpandCentre.java` |
| `string_matching.py` | `hashing_strings/StringMatching.java` |

The original technique organization, algorithm variants, explanatory themes, and test themes are retained in Java. The adaptation adds explicit type contracts, numeric boundary handling, delimiter-safe palindrome construction, a strict string decoder, and Java regression tests.
